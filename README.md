# tensura-fonts

A repository containing the fonts that were created based on the most prominent writing system used in the world of "Tensei Shitara Slime Datta Ken" or in short "Tensura". 

All fonts are fan-made. The manga and anime fully belong to their rightful owners, hence the fonts are not original. The glyphs the fonts contained came directly from depictions in the manga and anime adaptations.

Please note that these fonts do NOT cover EVERYTHING, but they are guaranteed to at least cover all English-equivalent letters (both uppercase and lowercase), numbers, and a few number of basic punctuations.

This repository is a derivative work based on *Tensei Shitara Slime Datta Ken* (*That Time I Got Reincarnated as a Slime*) authored by Fuse. Therefore, any usage of fonts included in this repository must conform with all provisions that apply to works derived from a copyrighted work.

# Changelog

## Release v1.2
- New discretionary ligatures "ic", "or", "ri", "ari", "ori", "aric", and "oric" (all in lowercase) are added to the "Aesthetic" variant. Unlike "ar", the aforementioned ligatures are simply the author's **fanon/head-canon**.
- New standard ligature "ri" is added to the "Plain" variant.
- Several and possibly distinct adjustments related to kerning for both the "Aesthetic" and "Plain" variants.

See [here](https://github.com/jnscrtm/tensura-fonts/releases/v1.2) for more details. 

## Release v1.1
- A new discretionary ligature "ar" is added to both "Plain" and "Aesthetic" variants. This is based on the anime, Season 4 Episode 13.
- The metadata is updated to reflect changes related to identity

See [here](https://github.com/jnscrtm/tensura-fonts/releases/v1.1) for more details.
