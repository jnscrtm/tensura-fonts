# tensura-fonts

A repository containing fonts that were created based on the writing system depicted in the manga and anime adaptations of *Tensei Shitara Slime Datta Ken* (That Time I Got Reincarnated as a Slime).

There are two variants provided by this repository.
1. "Aesthetic" variant. Designed to look fancy and somewhat calligraphic-ish.
2. "Plain" variant. Designed to (hopefully) look formal and plain (e.g. found in textbooks or any formal documents).

All fonts are fan-made. The manga and anime fully belong to their rightful owners, hence the fonts are not original. The glyphs the fonts contained came directly from depictions in the manga and anime adaptations.

Please note that these fonts do NOT cover EVERYTHING, but they are guaranteed to at least cover all English-equivalent letters (both uppercase and lowercase), numbers, and a few number of basic punctuations.
